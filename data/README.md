# Dados

## Como obter os dados

1. Baixe o [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
2. Extraia os arquivos CSV na pasta local `data/raw/`.
3. Não envie os arquivos CSV ao GitHub. Mantenha os dados brutos fora do versionamento.

## Organização local sugerida

```text
data/
└── raw/
    ├── olist_customers_dataset.csv
    ├── olist_orders_dataset.csv
    ├── olist_order_items_dataset.csv
    ├── olist_products_dataset.csv
    ├── olist_sellers_dataset.csv
    ├── olist_order_payments_dataset.csv
    ├── olist_order_reviews_dataset.csv
    ├── olist_geolocation_dataset.csv
    └── product_category_name_translation.csv
```

Confira os nomes dos arquivos na versão baixada.
